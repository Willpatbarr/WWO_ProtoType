Windows (64-bit) Development build of the `windows-release` branch: the same game as Pre-alpha 2.0.1.

Unzip, open the folder and start WhatWasOurs.exe. The build is not signed, so the first time Windows may show "Windows protected your PC": click More info, then Run anyway. Hosting or joining a game asks for network access through the firewall; allow it.

This build is the whole game. The repository holds the game's own code and art; the Fab packs it also uses (the enemies' skeletons, first-person animations, some sounds) stay out of the public repo, as their license requires, and are built into this build.

## New since Pre-alpha 2.0.0
- Shells keep their hard edges: flat plates and facets on every shell (most visibly shell 5's triangles and the default head's jaw) no longer look rounded or bubbled.

## Known issues
- The shell picker's fifth part makes the Shell tab's cards narrower.
- Testing on Windows was light: the build was started once before it was uploaded.
